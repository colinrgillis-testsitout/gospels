# Christian Texts

A Sefaria-style reader for the four gospels (KJV, public domain). Prototype with four sample passages.

## Run locally
    npm install
    npm run dev

## Deploy to Vercel
Import the repo at vercel.com/new (Vite is auto-detected), or run `npx vercel` from this folder.

## Where things live
- `src/data.js` – passages and connections (add chapters here)
- `src/main.js` – reader UI
- `src/style.css` – styles
